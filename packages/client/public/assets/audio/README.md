# Lyd

All lyd lages i dag med Web Audio i `packages/client/src/audio/`. Legg ekte lydfiler her
(`.ogg` eller `.mp3`) med disse navnene, så brukes de i stedet for de syntetiserte lydene:

`shot-revolver`, `shot-shotgun`, `shot-tommy`, `shot-rifle`, `siren`, `cash`, `engine`, `fire`, `music-day`, `music-night`
